# AWS Cloud Security Monitoring System

## Overview
This project demonstrates a cloud security monitoring solution built in AWS to detect unauthorized access to secrets and generate automated alerts.

## Technologies Used
- AWS CloudTrail
- AWS CloudWatch
- AWS SNS
- AWS Secrets Manager
- Amazon S3
- AWS IAM
- AWS CLI

## Security Scenario
Organizations often store sensitive information such as API keys, passwords, and database credentials in AWS Secrets Manager. Unauthorized access to these secrets can lead to data breaches and privilege escalation. This project monitors secret access activity and generates real-time alerts whenever a secret is retrieved.

## Detection Logic
<img width="1855" height="702" alt="cloudtrail-event-getsecretvalue" src="https://github.com/user-attachments/assets/d1b62047-9069-4d63-a6b8-13aabb36c737" />
The monitoring solution tracks the GetSecretValue API call generated by AWS Secrets Manager. Whenever this event appears in CloudTrail logs, CloudWatch increments a custom metric and evaluates alarm thresholds. If the threshold is met, SNS sends an email notification to the administrator.

## Troubleshooting
During testing, email alerts were not initially generated. Investigation revealed that the CloudWatch alarm was using the Average statistic instead of Sum, preventing the alarm from reaching the configured threshold. Updating the alarm configuration resolved the issue.

## Results
Successfully detected secret access events and generated automated email notifications through CloudWatch and SNS. The project demonstrated end-to-end cloud security monitoring, event detection, alerting, and notification capabilities.
